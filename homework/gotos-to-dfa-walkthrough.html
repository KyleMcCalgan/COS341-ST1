Turn the GOTO list into the control DFA

Nothing new is calculated here. Each line in the finished GOTO list already contains one DFA edge: its first item set is the source, its grammar symbol is the edge label, and its result is the destination.

Read one GOTO line as one arrow

GOTO(Ii, X) = Ij Draw: state i —X→ state j Example: GOTO(I4, +) = I5 means draw 4 —+→ 5.
ImportantUse only GOTO results that exist. A completed item has no symbol after its dot, so it produces no outgoing DFA edge. The reduction/accept information is added later when the parsing table is built.
