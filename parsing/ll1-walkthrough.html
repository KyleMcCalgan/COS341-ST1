Filling in — and then using — the LL(1) table

Same grammar as the LL(1) overview page: T→R, T→aTc, R→ε, R→bR, with Nullable(T)=Nullable(R)=true, FIRST(T)={a,b}, FIRST(R)={b}, FOLLOW(T)=FOLLOW(R)={c,$}. Three steppers below, in order: derive each rule's Look-Ahead Set first, then just read the table straight off those sets, then run the finished table on a real string. Each click is exactly one decision.

Part 1 — Derive the Look-Ahead Set for each rule

Before touching the table, work out one number per production: its Look-Ahead Set — every terminal that could legally trigger choosing that rule. This is exactly the quantity a homework question means when it asks "provide the Look-Ahead-Set for each of the grammar's rules." The formula is the same production-selection rule as before, just read as a set instead of a per-symbol test:

Look-Ahead Set of a production N → α LA(N → α) = FIRST(α) if α is not Nullable = FIRST(α) ∪ FOLLOW(N) if α is Nullable

Once every rule has its LA set, filling the table in Part 2 is just copying: place the rule in one column per symbol in its LA set. No re-deriving FIRST/FOLLOW at table-filling time.

Part 3 — Using the finished table to actually parse a string

Now the table is complete. We parse aabbbcc (plus end marker $) using the stack-and-table algorithm: pop the stack top; if it's a terminal, match it against the input; if it's a nonterminal, look up table[nonterminal, next input symbol] and push that production's right-hand side. One click = one action.
