Regex → NFA

Nondeterministic Finite Automata

An NFA is the stepping stone between a regex and something executable. It's allowed to be "wasteful" — multiple valid transitions from one state, ε-transitions that cost nothing to follow — because we're about to convert it into something deterministic anyway.

What makes it nondeterministic

Definition 1.1 (paraphrased) An NFA is: a finite set of states S, one start state s0 ∈ S, a subset F ⊆ S of accepting states, and a set of transitions T. Each transition connects two states and is labelled either by an alphabet character, or by ε (an epsilon-transition — free to follow, consumes no input).

A string is accepted if some sequence of choices — regular transitions and ε-transitions mixed freely — reads the whole string and ends on an accepting state. Other choices might dead-end; that doesn't matter, only one successful path needs to exist.

Practical task: given a small NFA and a string, trace (or rule out) an accepting path — this is different from "run the automaton," since you may need to try more than one branch before finding the one that works, or before concluding none does.

Building an NFA from a regex — fragment by fragment

The construction is compositional: build a small NFA fragment for each piece of the regex, each with exactly one dangling entry point and one dangling exit point, then wire fragments together following the regex's own structure. The final fragment's exit gets wired to one single accepting state.

Regex formFragment shape
aentry --a--> exit (one transition, labelled a)
s tentry --[fragment s]--> --[fragment t]--> exit (chain them: s's exit becomes t's entry)
s | ta new entry ε-branches into both fragment s and fragment t; both exits ε-join into a new exit
s*a new entry/loop-point ε-branches either straight to a new exit (zero repetitions), or into fragment s, whose exit ε-loops back to the same loop-point

This is exactly the general construction — expanding every shorthand (+, ?, character sets) into raw */| first works, but §1.3.1 gives optimised direct fragments for these instead, since expanding a deeply-nested + can blow the NFA up exponentially before you even get to the DFA stage.
