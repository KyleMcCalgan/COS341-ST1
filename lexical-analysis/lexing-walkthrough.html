Tracing maximal munch, including the backtrack

Lexing 3e-y against a combined number/float DFA — the same example described on the Lexers page, now step by step. This is the case that actually tests understanding: the scan reads past the token it ends up emitting, then has to back up.

The DFA being used q0 --digit--> q1 (accepts NUM) --digit--> q1 (self)
q1 --.--> q2 --digit--> q3 (accepts FLOAT) --digit--> q3 (self)
q1 or q3 --e--> q4 --(+/-)--> q5 --digit--> q6 (accepts FLOAT) --digit--> q6 (self)
q4 --digit--> q6 directly (exponent with no explicit sign)
